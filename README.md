# EyeBio Arcade

A responsive interactive biology game for learning the human eye. It includes a clickable 3D eye model, Light Path ordering, Rods vs. Cones sorting, and Anatomy Hotspots with a names-only Hint list.

## Run locally

```bash
pnpm install
pnpm run dev
```

## Build for GitHub Pages

```bash
pnpm run build
pnpm run preview
```

The repository is already configured with a GitHub Actions workflow. Upload the contents of this folder to a GitHub repository, enable **Settings → Pages → GitHub Actions**, and push to the `main` branch.
